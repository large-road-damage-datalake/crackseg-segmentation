# CrackSeg

## Overview

CrackSeg is a task-specific segmentation package derived from the CrackSeg dataset.

- Task: segmentation
- Images: 3540
- Annotations: 27164
- Classes: 1 (crack)
- Annotation format: binary PNG masks (255 = crack, 0 = background)
- Splits: train/val/test (test split has images only)

The source dataset contains 3,540 high-resolution images (3840x2160) captured from on-board vehicle cameras across roads in Shandong Province, China.
